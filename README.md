# Vietnamese Traffic Sign Detection Using YOLO11

## 1. Overview

This project focuses on detecting Vietnamese traffic signs using YOLO11, a deep learning object detection model. The system is trained on a labeled traffic sign dataset and tested on images and real-world video footage.

The project explores traffic sign detection, model evaluation, and prediction visualization using Python and the Ultralytics YOLO framework.

## 2. Objectives

- Detect Vietnamese traffic signs in images and videos.
- Train a YOLO11 model using a custom-labeled dataset.
- Evaluate model performance using object detection metrics.
- Visualize training and validation loss and mAP.
- Display predicted bounding boxes, class labels, and confidence scores.
- Test the trained model on real-world video footage.

## 4. Dataset

The project uses a Vietnamese traffic sign detection dataset exported in YOLO format.

The dataset configuration is loaded through `data.yaml`, which defines the dataset paths and traffic sign classes.

The model is trained to detect 17 traffic sign categories, including:

- No U-turn
- Motorcycle-related traffic signs
- Turn-left and turn-right signs
- Stop and no-stopping signs
- Road hazard warnings
- Pedestrian-related signs
- Speed-related signs

The dataset archive is not included in this repository. You must obtain the dataset separately and update the dataset path before training.

## 5. Model Training

The project uses the YOLO11n model initialized from `yolo11n.pt`.

### Training configuration

| Parameter | Value |
|---|---|
| Model | YOLO11n |
| Epochs | 100 |
| Image size | 640 × 640 |
| Batch size | 16 |
| Initial learning rate | 0.001 |
| Optimizer | SGD |
| Momentum | 0.937 |
| Weight decay | 0.0005 |
| Warmup epochs | 3 |
| Early stopping patience | 20 |
| Data augmentation | Enabled |

## 6. Model Evaluation

The notebook evaluates object detection performance using:

- **Precision:** Measures the proportion of predicted detections that are correct.
- **Recall:** Measures the proportion of ground-truth objects detected by the model.
- **mAP@0.5:** Mean Average Precision at an IoU threshold of 0.5.
- **mAP@0.5:0.95:** Mean Average Precision averaged across multiple IoU thresholds.

Training and validation loss curves, together with mAP curves, are plotted to help analyze model learning and performance.

Actual evaluation results will be added after verifying the final training run.

## 7. Prediction and Visualization

The notebook supports the following experiments:

### Image Detection
Runs inference on test images and saves the detection results with bounding boxes.

### Real-World Video Detection
Runs the trained model on a video file to test traffic sign detection under practical conditions.

### Bounding Box and Label Customization
Uses OpenCV to draw bounding boxes and display traffic sign labels with confidence scores. A class-mapping dictionary is used to convert model class IDs into the intended traffic sign labels.

## 8. Project Workflow

1. Install the Ultralytics package.
2. Extract and configure the dataset.
3. Load the YOLO11n pretrained model.
4. Train the model on the custom dataset.
5. Evaluate the model using Precision, Recall, and mAP.
6. Plot training and validation metrics.
7. Run inference on test images and real-world videos.
8. Customize bounding boxes and predicted class labels.
